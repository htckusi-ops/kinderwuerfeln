# 🎲 Kinderwürfeln

Ein kindgerechtes, grafisches Lernprogramm für Linux.
Kinder lernen **Addition und Subtraktion** spielerisch mit bunten Würfeln.

## Für wen?

Kinder ab ca. 4–8 Jahren, die Rechnen mit Würfeln üben möchten.

## Features

- **1–6 Würfel** frei wählbar
- Bunte, animierte Würfel mit Roll-Animation
- **Additions-** und **Subtraktionsaufgaben** auf Basis der gewürfelten Zahlen
- Große, gut lesbare Schrift – kindgerechtes Design
- Sofortiges Feedback: Sterne-Feuerwerk bei richtiger Antwort
- Punkte-Zähler motiviert zum Weitermachen
- Fenstergröße ist anpassbar

## Starten

```bash
pip install pygame
python3 wuerfeln.py
```

## Bedienung

| Aktion | Eingabe |
|---|---|
| Würfelanzahl wählen | `+` / `−` Buttons |
| Spiel starten | `Spielen!` Button |
| Würfeln | Button oder neues Spiel |
| Antwort eingeben | Zifferntasten |
| Antwort bestätigen | `Enter` oder `Prüfen`-Button |
| Zurück zum Menü | `Menü`-Button oder `Escape` |

## Voraussetzungen

- Python 3.8+
- [pygame](https://www.pygame.org/) ≥ 2.0

```bash
pip install -r requirements.txt
```
